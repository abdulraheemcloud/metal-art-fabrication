# Metal Art Fabrication

A responsive single-page website for Metal Art Fabrication, a metal fabrication and welding business based in Peelamedu, Coimbatore.

## Tech Stack

- **React 19** — UI library
- **Vite 7** — build tool and dev server
- **TypeScript 5.9** — type safety
- **React Router 6** — client-side routing
- **Tailwind CSS 3** — utility-first styling

## Scripts

- **Local development:** `npm run dev`
- **Production build:** `npm run build`
- **Preview production build:** `npm run preview`

## Pages

- `/` — Home (Hero, Services, Gallery, About, Why Choose Us, Process, Enquiry CTA, Location)
- `/about` — About page
- `/services` — Services page
- `/projects` — Projects/Portfolio page
- `/contact` — Contact page with enquiry form
- `*` — 404 Not Found

## Current Status

This is a **reusable demo/template**. All service descriptions, project entries, and contact information are placeholder content prepared for demo purposes.

Real business content, contact details, project photography, domain configuration, and backend integration will be added after customer confirmation.

## Notes

- The contact form validates locally and does not submit to a backend
- Scroll-reveal animations include a no-JavaScript fallback
- A runtime error boundary catches rendering errors and displays a fallback UI
